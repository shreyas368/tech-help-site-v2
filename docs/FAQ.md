🟦 What is Tech Help?
Tech Help is a support system where users can report problems, request features, and upload files to help diagnose issues. You can submit reports through GitHub Issues, the Problem Report Form, or the File Upload Form depending on your needs.

🟦 How do I report a problem?
You have two options:

GitHub Issues — Best for quick bug reports or small problems.

Problem Report Form — Best for detailed reports with structured questions.

If you need to upload screenshots or logs, use the File Upload Form.

🟦 When should I use GitHub Issues instead of the Google Forms?
Use GitHub Issues when:

You found a small bug

You want to request a feature

You want to discuss something with maintainers

You don’t need to upload files

Use the Google Forms when:

You want a structured report

You need to upload screenshots, logs, or videos

You want to provide detailed information

🟦 Do I need a Google account to upload files?
Yes. Google requires sign‑in for file uploads.
You can still submit the Problem Report Form without signing in.

🟦 What file types can I upload?
You can upload:

Images (PNG, JPG, GIF)

Logs (TXT, LOG)

Documents (PDF)

Short videos (MP4, MOV)

Maximum: 5 files, up to 1 GB each.

🟦 How do I upload screenshots or logs?
Use the File Upload Form.
After uploading, you can reference your submission in a GitHub Issue if needed.

🟦 Can I track my issue after submitting the Google Form?
Yes — if you want public tracking, open a GitHub Issue after submitting the form.
You can include your form timestamp or summary.

🟦 Where can I request new features?
Use the Feature Request Issue Template:

Create a Feature Request

Or submit a detailed idea through the Problem Report Form.

🟦 What if I have sensitive information?
Do not post sensitive data publicly.
Upload files through the File Upload Form or describe the issue without exposing private information.
