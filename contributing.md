# Contributing to Tech Help

Thank you for helping improve Tech Help! We welcome both quick reports and detailed submissions.  
Please follow the guidelines below to make sure your contribution is handled smoothly.

---

## 🐞 Reporting Problems

You have two options for reporting issues:

1. **GitHub Issues (Quick Reports)**  
   - Use the [Issues tab](../../issues) for short bug reports or questions.  
   - Ideal for small problems, typos, or quick feedback.  
   - Please include steps to reproduce if possible.

2. **Google Forms (Detailed Reports)**  
   - Use our [Problem Report Form](https://docs.google.com/forms/d/e/1FAIpQLSd_N_QPYF5zpOEjFwuX03t11mNfRhuO4C9NjL3jz1ufY4LE1A/viewform?usp=publish-editor) for structured reports.  
   - If you need to upload screenshots, logs, or other files, use our [File Upload Form](https://docs.google.com/forms/d/e/1FAIpQLSc-X1__iICZIyn-bn11Rr9cAH6JNVlETq-l4n9bVNhtShbG-Q/viewform?usp=publish-editor).  
   - File uploads require a Google account. Please keep uploads under 500 MB unless absolutely necessary.

---

## ✨ Feature Requests

- Use GitHub Issues for new ideas or feature requests.  
- Clearly describe the problem your idea solves.  
- If you have supporting files, attach them via the File Upload Form.

---

## 🔒 Security Issues

- Do **not** open a public issue for security vulnerabilities.  
- Please report them privately following our [Security Policy](SECURITY.md).

---

## ✅ Workflow Summary

- **Small bug or typo** → GitHub Issue  
- **Detailed problem with files** → Google Forms + File Upload  
- **New feature idea** → GitHub Issue (+ optional File Upload Form)
